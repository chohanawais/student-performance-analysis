# Student Performance Analysis

## Project Overview
This project analyzes student marks using Python, Pandas, SQLite, andMatplotlib


## Features

- Store student records in SQLite database
- Calculate average, highest, and lowest marks
- Identify pass and fail students
- Generate student performance graphs


## Technologies Used
- Python
- Pandas
- SQLite
- Matplotlib

## How to Run
Run the following command:


'''bash
python3 performance_graph.py
'''

## Purpose
This project is created for practical Data Science and Data Analyst learning.
